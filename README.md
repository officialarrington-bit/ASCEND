# ASCEND

ASCEND is a student-athlete career platform prototype for Campbell University’s Presidential Innovation Challenge. Athletes can show their interests and availability, discover participating professionals and alumni, prepare introductions, and explore career experiences.

**[Open the live Campbell ASCEND demo](https://ascend-campbell-demo.officialarrington.chatgpt.site)**

## Run locally

Requires Node.js and npm.

```sh
npm ci
npm run build
npm run preview
```

Vite serves the generated `dist/` site. The interface is a browser-local demonstration: profiles, connection requests, interest registrations, and role views do not send data to a server or employer. Reset Demo restores the initial state.

## What is validated

The featured KS Bank shadow-day concept was discussed with Travis Bailey, who confirmed the January 20, 2027, 9 AM–4 PM schedule and offered KS Bank’s participation in a Campbell pilot. Tim Aguglia has agreed personally to help develop a flexible healthcare experience; this does not imply Regeneron corporate sponsorship or a live opening. Other sample listings are labeled **Concept** and use fictional companies. Campbell adoption, participant selection, and shared production infrastructure remain future work.
